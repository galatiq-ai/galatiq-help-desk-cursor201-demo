# Runbook: VPN gateway not responding

**Symptoms:** Remote users cannot connect; "gateway not responding".

**Group:** Network & Infrastructure · **Priority:** P2 (many users) or P3 (single user).

## Steps

1. Check VPN appliance cluster health and ISP circuit status.
2. If widespread, open bridge and page Network on-call.
3. Dedupe duplicate tickets from same outage.
4. Workaround: split-tunnel guidance or alternate POP—human sends.
